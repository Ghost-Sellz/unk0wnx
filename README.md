# Portfolio

Personal portfolio website of **Salah Ahmad Al-Zibari**, a developer from Sønderborg, Denmark, who builds things for the web and explores cybersecurity.

Built from scratch with plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.


## Project structure

```
.
├── index.html   # Page markup and content
├── style.css    # All styling, design tokens and responsive rules
└── script.js    # Mobile menu, scroll reveal and footer year
```
Change these values to re-theme the whole site. Font stacks (`--font-serif`, `--font-sans`, `--font-mono`) and layout values (`--page-width`, `--gutter`, `--header-height`) are defined in the same block.
